## Mistakes to emphasize

- Starting fresh when Smart Resume data exists.
- Loading the wrong shared pending candidate.
- Expecting Newbie Shift reschedules or completed transfers to appear as resumable sessions.
- Creating a fresh continuation because a similar candidate name appears.
- Omitting fail reasons or Other notes.
- Treating prior technical issues as current NC/NS evidence.
- Describing an incomplete follow-up as a failed certification.

## Closing summary

“Use normal flow for same-session work, Smart Resume for saved calls, and Supervisor Transfer Only only when no resumable record should be used. Confirm the candidate and attempt state before scoring.”
