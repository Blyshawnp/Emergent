# MTS Tutorial Video Plan

## Metadata

- Title: MTS Core Workflow Tutorial Series
- VideoKey: `mts-production-plan` (planning-only; do not publish as a tutorial row)
- Category: Getting Started
- HelpTopicKey: `getting-started`
- Audience: MTS trainers, evaluators, and training reviewers
- Duration: Seven videos; approximately 45-57 minutes total

## Objectives

- Prepare a new trainer to complete the core workflow without costly status, grading, follow-up, or Form Fill errors.
- Provide short, searchable modules attached to matching Help articles.
- Keep policy statements separate from verified application behavior.

## Prerequisites

- Current release-candidate MTS build and written Help.
- Approved synthetic dataset covering lookup, final attempt, Smart Resume, incomplete follow-up, and form states.
- Recording environment that meets `VIDEO-RECORDING-STANDARDS.md`.

## Demo data/setup

- Use one clearly labeled synthetic candidate per outcome: new, prior failed attempt, resumed transfer, incomplete Newbie Shift, and completed History.
- Configure safe generic Discord templates and screenshots.
- Use a non-production form-fill demonstration that cannot create a real candidate submission.
- Fix the demo clock so the less-than-24-hour and exactly-24-hour examples are unambiguous.

## Recording checklist

- [ ] Confirm labels against the current MTS source.

- [ ] Hide identities, accounts, private locations, and browser suggestions.
- [ ] Capture all priority MTS screenshots.

## Exact narration

Series intro: “This MTS series follows the certification workflow in the same order you use it on the job. Each video focuses on the decisions that protect the candidate record: choosing the correct candidate, scoring only what happened, using the right follow-up path, and verifying Form Fill before you finish.”

Series safety card: “MTS labels are workflow facts. Department authorization and exception policy come from certification leadership. When the app blocks a candidate or an action requires approval, stop and use the approved escalation process.”

Series outro: “Use the matching Help article whenever the screen or status differs from this recording. Written Help remains the source when a tutorial video is unavailable.”

## Exact on-screen actions

1. Show the title slate and version/date.
2. Open Help > Tutorial Videos to demonstrate where each module will live.
3. Select each category in series order without opening private content.
4. End on the MTS Home screen with Help visible in navigation.

## Callout text

- `Verify before scoring`
- `Record what happened`
- `Pending is not approved`
- `Form Filled is not submitted`
- `Use Smart Resume when prior calls exist`

## Pause/zoom notes

- Pause on eligibility blocks, destructive confirmations, the exact 24-hour result, Form Filled warnings, and History status chips.
- Use 125% editor crops for one decision panel at a time.

## Mistakes to emphasize

- Selecting the wrong candidate or forcing a blocked attempt.
- Using Other without notes or using Tech Issue as a failure reason.
- Starting Supervisor Transfer Only when Smart Resume data exists.
- Treating Pending as approved.
- Calling Form Filled submitted or refilling after a status warning.

## Closing summary

The seven modules cover the full MTS path and meet the launch map without adding an unnecessary eighth video.
