# SAM Short Intro Video Script

Target length: 60 to 90 seconds

Tone: relaxed and quick. This can be used as an optional SAM tutorial intro or replacement video. Users can skip it.

## Script

Say:

"Welcome to SAM, the Smart Alert Manager. SAM helps admins manage MTS notifications and candidate tracking records."

Show:

- SAM home
- Status chips
- Main action buttons

Say:

"Use Notifications to add, edit, enable, disable, import, export, and refresh alert rows. Live Preview lets you check ticker, banner, and popup behavior before changes go live."

Show:

- Notifications table
- Add Notification
- Live Preview

Say:

"Candidate Tracking shows pending supervisor transfers, incomplete records, failed final attempts, withdrawn candidates, passed certifications, archived candidates, and active candidates."

Show:

- Candidate Tracking
- Candidate Search

Say:

"Archive keeps a record but removes it from active views. Delete is different and should only be used intentionally."

Show:

- Archive action
- Archived Candidates view

Say:

"Help includes searchable topics, Tutorial Videos, Quick Start Choices, Replay Guided Walkthrough, and local preferences. Tutorial content is not edited in Settings."

Show:

- Help and Settings

Say:

"You can skip this intro or replay it later from Help whenever you need a refresher."
