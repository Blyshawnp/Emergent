# MTS Short Intro Video Script

Target length: 60 to 90 seconds

Tone: relaxed and quick. This can be used as an optional tutorial intro or replacement video. Users can skip it.

## Script

Say:

"Welcome to Mock Testing Suite. This is the tool you’ll use to run certification mock sessions from start to finish."

Show:

- Home screen
- Sidebar

Say:

"Start New Session takes you through Basics, Calls, Supervisor Transfer, and Review. Basics checks readiness first, including headset, VPN, and browser setup."

Show:

- Basics
- Headset field
- VPN/browser questions

Say:

"During calls, choose the call type, mark Pass or Fail, and select only the coaching that was actually given. If a fail reason needs more context, use Add Detail."

Show:

- Calls
- Coaching
- Fail reasons

Say:

"Discord Posts and Screenshots are available from the sidebar. Copy buttons copy the exact approved text or asset you need."

Show:

- Discord Posts
- Screenshots

Say:

"At Review, check the summaries and Final Readiness Judgment before finishing. If Gemini is unavailable, the app still gives you fallback summaries."

Show:

- Review
- Final Readiness
- Summary status

Say:

"You can replay the tutorial from Help any time. If you already know the flow, you can skip this intro and start working."

Show:

- Help
- Replay Tutorial
