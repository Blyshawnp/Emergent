# Defaults and Editable Content Map

This guide maps the local default sources for MTS and SAM. It intentionally does not treat live Google Sheets or Google Docs as the editable source for this guide, but those remote admin sources can override packaged defaults at runtime when configured and reachable.

Do not put secrets, spreadsheet IDs, service-account details, tokens, passwords, or private keys in this document.

## Runtime Priority

Most editable content is resolved in this order:

1. User-saved SQLite settings.
2. Google Sheets or Google Docs admin overrides, when configured and reachable.
3. Local packaged files under `docs/admin-content-package/csv-tabs/` or `backend/defaults/`.
4. Built-in Python or React fallback values.

Packaged apps need a rebuild whenever a local file or source-code fallback changes. Google Sheet or Google Doc changes can take effect without rebuilding when the app can load them.

## Local Fallback File Locations

Primary offline defaults live in:

- `backend/defaults/`
- `docs/admin-content-package/csv-tabs/`
- `backend/content/app_content.json`
- selected fallback constants in `backend/server.py`
- selected UI fallback constants in `frontend/src/`
- public assets in `frontend/public/`

`backend/content/app_content.json` is loaded as local JSON content when present. The backend then falls back to local CSV/Markdown defaults and finally built-in constants.

## Google Override Note

Google Sheets and Google Docs are runtime override mechanisms, not the local source map for this guide. When remote content is configured and reachable, it can override local packaged defaults without rebuilding. When it is missing, invalid, or unreachable, the app falls back to packaged defaults and built-in values.

Do not include Google Sheet IDs or service-account details in local docs unless explicitly approved for a non-secret configuration guide.

## Packaging Note

For local default changes to reach packaged users, rebuild the appropriate app output and refresh `production-ready` if preparing a release. Do not commit generated outputs such as `frontend/build/`, `desktop/dist/`, `desktop/dist-notification-manager/`, installers, blockmaps, `latest.yml`, `app.asar`, logs, or `production-ready/`.
