# Google Form Fields: App Help / Support Request

Recommended form title:

`MTS / SAM App Help and Support Request`

Recommended description:

Use this form when you need help with MTS or SAM installation, setup, settings, sounds, visuals, sessions, form filling, Discord posts, payment simulation, headset/Basics, notifications, Candidate Tracking, import/export, archive/search, or an app that will not open. Do not submit passwords, private keys, API keys, tokens, or service-account files.

## Field List

### 1. Name

Question type:

Short answer

Required:

Yes

### 2. Email

Question type:

Short answer

Required:

Yes

Validation:

Email address

### 3. Preferred contact method

Question type:

Multiple choice

Required:

Yes

Options:

- Email

- Phone

Question type:

Short answer

Required:

No

Required only if Discord is the preferred contact method.

### 5. Phone number

Question type:

Short answer

Required:

No

Required only if Phone is the preferred contact method.

Question type:

Multiple choice

Required:

Yes

Options:

- MTS

- Both

Question type:

Multiple choice

Required:

Yes

Options:

- Setup Wizard help
- Tutorial help
- Settings help
- Sound issue

- MTS form not filling completely
- MTS Discord post issue

- MTS headset/Basics issue

### 8. Urgency

Question type:

Multiple choice

Required:

Yes

Options:

- Normal
- Urgent

Help text:

Choose Urgent only when the app will not open, required work is blocked, shared data may be wrong, or a tester/admin cannot complete required work.

### 9. Best time to contact

Question type:

Short answer

Required:

No

Help text:

Include timezone if relevant.

### 10. Description of help needed

Question type:

Paragraph

Required:

Yes

Help text:

Describe what help you need. Include any error wording if safe to share. Do not include credentials or private keys.

### 11. What have you tried?

Question type:

Paragraph

Required:

No

Examples:

- Restarted app
- Checked Help
- Replayed tutorial
- Refreshed from Sheet
- Tried manual update
- Reinstalled app

### 12. Screenshot/file upload instructions

Question type:

Paragraph or Section text

Required:

No

Recommended text:

If you have a screenshot, screen recording, log excerpt, or sample file, attach it using the upload field if one is enabled for this form. Do not upload passwords, private keys, API keys, tokens, service-account files, or files containing private candidate data unless support has specifically asked for a redacted copy.

Optional upload field:

File upload

Upload limits:

- Allow images and video if needed.
- Keep file size modest.
- Require sign-in only if that is acceptable for the tester/admin group.

### 13. Permission to contact

Question type:

Multiple choice

Required:

Yes

Options:

- Yes
- No

Help text:

Select Yes if support may contact you using the preferred contact method.

## Recommended Response Sheet Columns

Google Forms creates answer columns automatically. Add these support tracking columns to the right:

- Status
- Assigned to
- Reviewed date
- Follow-up needed
- Follow-up date
- Release blocker
- Resolution notes
- Closed date

## Urgent Detection

This form should be treated as urgent when:

- `Urgency` equals `Urgent`

Urgent alert summary should include:

- App
- Support category
- Urgency
- Name
- Preferred contact method
- Best time to contact
- Description of help needed
